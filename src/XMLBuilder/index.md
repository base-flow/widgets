# XMLBuilder

*本方法由`@baseflow/react`提供

## 介绍

生成/解析/验证XML，集成自`fast-xml-parser@5.3.2`，详细说明见`fast-xml-parser`：

```ts
export { XMLBuilder, XMLParser, XMLValidator } from 'fast-xml-parser';
```

## 示例

```ts

import { XMLBuilder, XMLParser, XMLValidator } from '@baseflow/react';

```

## APi

| 方法名        |  说明   |
| ------------ | ------ |
| XMLBuilder      | 参见：`fast-xml-parser -> XMLBuilder`  |
| XMLParser | 参见：`fast-xml-parser -> XMLParser`  |
| XMLValidator | 参见：`fast-xml-parser -> XMLValidator`  |
